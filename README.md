# Homebrew Tap

Homebrew formulae and casks for [alexey1312](https://github.com/alexey1312) projects.

## Install

```bash
brew install alexey1312/tap/<formula>      # CLI tools
brew install --cask alexey1312/tap/<cask>  # macOS GUI apps
```

## Available

### Formulae (CLI)

| Formula | Description |
|---------|-------------|
| `exfig` | Export colors, typography, icons, and images from Figma to Xcode, Android, Flutter, and Web |
| `clai` | LLM-powered CLI help assistant |
| `swiftindex` | Swift-native semantic code search for AI coding assistants via MCP |

### Casks (GUI apps)

| Cask | Description |
|------|-------------|
| `ruensync` | macOS menubar app that keeps a QMK keyboard's `cur_lang` in sync with the active macOS input source |
